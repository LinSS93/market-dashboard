# Market Dashboard

Market Dashboard 是一个帮助个人投资者整理信息、跟踪自选股并发现值得进一步研究标的的本地看板。

> **仅供研究辅助。** 本项目不会下单，不构成投资建议、收益承诺或替代独立判断。

## 可以做什么

- **自选股与持仓跟踪**：集中查看关注标的的价格、趋势、风险提示与关键价位。
- **机会雷达**：把公开事件、趋势变化和基本面变化整理成研究档案，帮助你发现“为什么值得现在关注”。
- **持续研究候选池**：将不同来源的信号汇总为待研究列表，区分新信号、多来源确认、风险待核验与待评分标的。
- **杠杆 ETF 跟踪**：辅助观察杠杆 ETF 的风险与行情变化。
- **盘后复盘**：通过实验室查看历史情景、证据与复盘记录。

机会雷达只帮助排序“先研究什么”，不会给出买入或卖出指令。

## 如何开始

Windows 用户可从 [最新发布版本](https://github.com/LinSS93/market-dashboard/releases/latest) 下载便捷 ZIP，解压后双击 `Start-Market-Dashboard.cmd`。

第一次使用时，按浏览器提示创建本地管理员即可。详细步骤请见[Windows 快速使用](docs/windows-quick-start.md)和[使用说明](docs/user-guide.md)。

## 公开版说明

公开版本不包含任何个人自选股、持仓、交易记录、账户信息、数据源凭据或真实行情结果。所有个人数据都只保存在你自己的电脑上。

如果希望启用可选的数据与研究功能，请先阅读[本地配置说明](docs/open-source-setup.md)和[数据源责任说明](docs/data-sources.md)。
