# Market Dashboard

Market Dashboard 是一个帮助个人投资者整理信息、跟踪自选股，并发现值得进一步研究标的的本地看板。

> **仅供研究辅助。** 本项目不会下单，不构成投资建议、收益承诺或替代独立判断。

## 核心功能

### 股票监控

股票监控把自选股和持仓集中到同一处，帮助你持续判断一只股票当前处在什么状态，以及下一步该重点观察什么。

- 汇总价格、趋势、成交变化、关键价位和风险提示，减少在不同页面之间来回切换。
- 决策卡会把趋势、波动、量价与风险条件整理为当前观点、判断依据和后续观察条件。
- 详情页提供公司概览、研究材料、历史信号表现和分组管理，方便长期跟踪。

它的作用不是预测涨跌，而是把原本分散的行情与风险信息整理为可复查的研究上下文，避免只凭单一指标下判断。

### 机会雷达

机会雷达用于从更广的市场信息中找出“为什么值得现在进一步研究”的变化，而不是给出一张简单的股票排行榜。

- 它把公开披露、趋势变化和基本面变化整理为带来源的研究档案。
- 再将不同来源的信号汇总为持续研究候选池，区分新信号、多来源确认、风险待核验和待评分标的。
- 每条档案都保留触发原因、原始来源、确认条件、失效条件与后续复核线索，便于核验和回看。

机会雷达的实现逻辑是“先发现变化，再核验事实，最后排序研究优先级”。它只回答“今天先看什么”，不输出买入或卖出指令。

## 其他功能

- **杠杆 ETF 跟踪**：关联杠杆 ETF 与对应正股，集中观察正股方向、价格、溢折价和产品风险。
- **实验室**：查看历史情景、证据记录和规则验证结果；它不改变正式判断。

## 如何开始

Windows 用户可从 [最新发布版本](https://github.com/LinSS93/market-dashboard/releases/latest) 下载便捷 ZIP，解压后双击 `Start-Market-Dashboard.cmd`。

第一次使用时，启动后直接在浏览器中打开本地地址即可。详细步骤请见[Windows 快速使用](docs/windows-quick-start.md)和[使用说明](docs/user-guide.md)。

## 公开版说明

公开版本不包含任何个人自选股、持仓、交易记录、账户信息、数据源凭据或真实行情结果。所有个人数据都只保存在你自己的电脑上。

如果希望启用可选的数据与研究功能，请先阅读[本地配置说明](docs/open-source-setup.md)和[数据源责任说明](docs/data-sources.md)。
