# Data-source responsibilities

Market Dashboard includes adapters for public exchange disclosures, market-data services, and optional LLM providers. Source code does not grant redistribution or commercial-use rights.

- Obtain your own credentials where required.
- Do not commit API keys, cookies, collected prices, announcements, PDFs, or LLM responses.
- Respect terms, rate limits, robots policy, attribution requirements, and regional restrictions.
- Keep automated scanning disabled until your intended use is permitted.
- Treat filings and news as source material to verify, never as a recommendation.

Common integrations may include exchange disclosure systems such as SEC EDGAR, HKEX, or CNINFO, market-data services, and optional LLM APIs. Their availability and terms can change; consult each provider directly.
